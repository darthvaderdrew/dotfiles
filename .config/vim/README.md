# Vim

## Dependencies

Install [vim-plug](https://github.com/junegunn/vim-plug) to manage plugins.

## Setup

Install plugins:

```vim
:PlugInstall
```

## Maintenance

Update plugins:

```vim
:PlugUpdate
```

Update vim-plug:

```vim
:PlugUpgrade
```

Remove unused plugins:

```vim
:PlugClean
```
