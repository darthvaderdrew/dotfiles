# tmux

## Dependencies

Install [TPM](https://github.com/tmux-plugins/tpm) to manage plugins.

```sh
git clone https://github.com/tmux-plugins/tpm ~/.config/tmux/plugins/tpm
```

## Setup

Install plugins:

`prefix` + `I`

## Maintenance

Update plugins:

`prefix` + `U`

Remove unused plugins:

`prefix` + `Alt+u`
